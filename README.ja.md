<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/QuickRecipe/raw/main/icon.png" width="35"/> Quick Recipe</h1>

<p align="center">
  Quick Recipeは、あなたの好みや食事のスタイル、日々のニーズに合わせたパーソナライズされたレシピを提供し、毎日の献立作りをシンプルにします。
</p>

## <img src="https://github.com/KrishBharadwaj5678/QuickRecipe/raw/main/assets/readme/features.gif" width="35"/> 機能

| **機能**              | **説明**                                        |
| ------------------- | --------------------------------------------- |
| 🔎 **スマートレシピ検索**    | 食材名を使ってレシピをすばやく検索できます。                        |
| 🌐 **2言語対応**        | 英語とヒンディー語のレシピに対応しています。                        |
| 🍳 **ステップごとの調理ガイド** | 分かりやすい手順に沿って料理を作ることができます。                     |
| 📋 **レシピ概要**        | レシピの重要な情報をすばやく確認できます。                         |

## <img src="https://github.com/KrishBharadwaj5678/QuickRecipe/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/QuickRecipe.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd QuickRecipe
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash
streamlit run app.py
```
